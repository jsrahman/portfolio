## 🛠️ Running Locally

### Prerequisites

- Node.js 18+
- npm / pnpm

### Install & Start

```bash
# Clone the repo
git clone https://github.com/jsrahman/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Run Tests

```bash
npm test
```
